## MONTH 1: Data Fundamentals and Excel

**Objective:** Build a strong foundation in data, business information, spreadsheets and data structures.

### Week 1: Understanding Data and the IT Industry

| Day   | 3 Hours: Concepts + Documentation                                                | 2 Hours: Hands-on Activity           |
| ----- | -------------------------------------------------------------------------------- | ------------------------------------ |
| Day 1 | Introduction to IT industry, data-related careers, data engineering vs analytics | Explore sample datasets              |
| Day 2 | Data, information, databases, structured and unstructured data                   | Create structured datasets           |
| Day 3 | Rows, columns, records, fields, data types and formats                           | Create customer and product datasets |
| Day 4 | Data lifecycle, data sources, data flow and business applications                | Map a simple business data flow      |
| Day 5 | Introduction to business requirements and data documentation                     | Prepare a data dictionary            |

**Weekly Deliverables:**

* Data fundamentals documentation.
* Three sample datasets.
* Data dictionary.
* Business data flow diagram.

### Week 2: Excel Fundamentals

| Day   | 3 Hours: Concepts + Documentation                           | 2 Hours: Hands-on Activity        |
| ----- | ----------------------------------------------------------- | --------------------------------- |
| Day 1 | Excel interface, workbooks, worksheets, cells and ranges    | Create structured Excel workbooks |
| Day 2 | Data types, formatting, tables and named ranges             | Create employee and sales tables  |
| Day 3 | Relative, absolute and mixed references                     | Practice formulas                 |
| Day 4 | SUM, AVERAGE, COUNT, COUNTA, MIN, MAX                       | Build sales calculations          |
| Day 5 | Sorting, filtering, freezing panes and Excel best practices | Build a monthly sales tracker     |

**Weekly Deliverables:**

* Sales tracker.
* Employee master dataset.
* Excel fundamentals documentation.

### Week 3: Excel Functions and Data Cleaning

| Day   | 3 Hours: Concepts + Documentation                  | 2 Hours: Hands-on Activity                |
| ----- | -------------------------------------------------- | ----------------------------------------- |
| Day 1 | Logical functions: IF, IFS, AND, OR                | Create business classification rules      |
| Day 2 | Text functions: LEFT, RIGHT, MID, LEN              | Extract information from customer records |
| Day 3 | TRIM, UPPER, LOWER, PROPER, SUBSTITUTE             | Clean customer information                |
| Day 4 | IFERROR, date functions and conditional formatting | Create exception reports                  |
| Day 5 | Data cleansing methodology and documentation       | Clean a messy customer database           |

**Weekly Deliverables:**

* Clean customer database.
* Excel function reference guide.
* Data cleansing report.

### Week 4: Excel Lookup and Business Analysis

| Day   | 3 Hours: Concepts + Documentation                  | 2 Hours: Hands-on Activity                |
| ----- | -------------------------------------------------- | ----------------------------------------- |
| Day 1 | Lookup concepts and relationships between datasets | Understand customer-product relationships |
| Day 2 | XLOOKUP and VLOOKUP                                | Retrieve customer and product information |
| Day 3 | INDEX and MATCH                                    | Perform advanced lookups                  |
| Day 4 | SUMIFS, COUNTIFS, AVERAGEIFS                       | Analyse business performance              |
| Day 5 | Introduction to business reporting                 | Build a retail sales analysis workbook    |

**Monthly Assessment:**

Build a complete Excel-based retail analysis solution.

The learner should demonstrate the ability to:

* Understand raw data.
* Clean and standardise data.
* Apply formulas.
* Combine multiple datasets.
* Generate business insights.
