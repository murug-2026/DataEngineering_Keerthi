# MONTH 2: Advanced Excel and Data Quality

**Objective:** Develop analytical thinking and understand data quality, aggregation and reporting.

### Week 5: Data Quality Management

| Day   | 3 Hours: Concepts + Documentation                                      | 2 Hours: Hands-on Activity             |
| ----- | ---------------------------------------------------------------------- | -------------------------------------- |
| Day 1 | Data quality dimensions: accuracy, completeness, consistency, validity | Inspect a sample dataset               |
| Day 2 | Missing values and null values                                         | Identify and handle missing records    |
| Day 3 | Duplicate records and inconsistent values                              | Remove duplicates and standardise data |
| Day 4 | Data validation and business rules                                     | Create validation rules in Excel       |
| Day 5 | Data quality reporting and exception management                        | Build a data quality report            |

Deliverables:

* Data quality checklist.
* Data quality report.
* Cleansed customer master.
