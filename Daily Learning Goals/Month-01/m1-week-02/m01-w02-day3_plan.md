# 📙 **DAY 3 — Relative, Absolute & Mixed References**  
### **Conceptual Understanding (3 hours)**  
- What is a **cell reference**?  
- What is a **relative reference** (A1)?
  - How does it behave when copied across rows/columns?  
- What is an **absolute reference** ($A$1)?
  - Why do we lock both row and column?  
- What is a **mixed reference** ($A1 or A$1)?  
- Why do formulas break when references are incorrect?  
- How do references affect:
  - Tax calculations  
  - Commission calculations  
  - Discount calculations  
  - Lookup formulas  
- What is the difference between copying formulas horizontally vs vertically?  
- How do references behave inside Excel Tables (structured references)?  
- Why do business analysts rely heavily on absolute references?

### **Hands-On Practice (2 hours)**  
- Build a tax calculation formula using absolute references.  
- Build a commission formula using mixed references.  
- Create a discount table and apply formulas across rows/columns.  
- Practice dragging formulas and observing reference changes.  
- Convert formulas to structured references inside a table.

### **Reflection (1 hour)**  
- Can you explain when to use $A$1 vs A$1 vs $A1?  
- Can you fix a broken formula caused by wrong references?
