# 📒 **DAY 5 — Sorting, Filtering, Freezing Panes & Excel Best Practices**  
### **Conceptual Understanding (3 hours)**  
- What is **sorting**?
  - Ascending vs descending  
  - Sorting by multiple columns  
- What is **filtering**?
  - Basic filters  
  - Advanced filters  
  - Filter by text, number, date  
- What is **freezing panes**?
  - Freeze top row  
  - Freeze first column  
  - Freeze custom panes  
- What are Excel **best practices**?
  - Avoid merged cells  
  - Keep headers clean  
  - Use tables instead of raw data  
  - Maintain consistent formats  
  - Avoid blank rows  
  - Use meaningful sheet names  
  - Document assumptions  
- Why do poorly structured sheets cause errors in analysis?  
- How do sorting and filtering help in business reporting?

### **Hands-On Practice (2 hours)**  
- Sort sales data by region and then by amount.  
- Filter employees by department, salary range, or status.  
- Freeze header row for large datasets.  
- Build a **Monthly Sales Tracker**:
  - Month  
  - Product  
  - Sales Amount  
  - Total  
  - Average  
  - Min/Max  
- Apply best practices to clean the tracker.

### **Reflection (1 hour)**  
- Can you sort and filter without damaging the dataset?  
- Can you design a clean sales tracker using best practices?
