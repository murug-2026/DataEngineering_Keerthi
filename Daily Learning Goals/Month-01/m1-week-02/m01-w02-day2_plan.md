# 📗 **DAY 2 — Data Types, Formatting, Tables & Named Ranges**  
### **Conceptual Understanding (3 hours)**  
- What are Excel’s **data types**?
  - Number  
  - Text  
  - Date  
  - Time  
  - Boolean  
- How does Excel internally store dates (serial numbers)?  
- What is the difference between **data type** and **format**?  
- What are common formatting options?
  - Number formatting  
  - Currency  
  - Percentage  
  - Date formats  
  - Custom formats  
- What is an **Excel Table**?
  - How do tables improve filtering, sorting, and formulas?  
  - What is structured referencing?  
- What are **named ranges**?
  - Why are they useful in formulas?  
  - How do you create and manage named ranges?  
- What is the difference between:
  - Table name  
  - Column name  
  - Named range  
- What formatting mistakes cause formula errors?
  - Numbers stored as text  
  - Dates stored as text  
  - Inconsistent formats  
- Why is consistent formatting critical for business datasets?

### **Hands-On Practice (2 hours)**  
- Create an **Employee Table** with proper data types.  
- Create a **Sales Table** with currency formatting.  
- Convert raw data into Excel Tables.  
- Create named ranges for:
  - Employee IDs  
  - Product Names  
  - Sales Amounts  
- Experiment with different date formats.  
- Identify and fix numbers stored as text.

### **Reflection (1 hour)**  
- Can you explain why formatting is not the same as data type?  
- Can you identify formatting errors in a dataset?
