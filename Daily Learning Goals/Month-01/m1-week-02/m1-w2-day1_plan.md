
# 📘 **DAY 1 — Excel Interface, Workbooks, Worksheets, Cells & Ranges**  
### **Conceptual Understanding (3 hours)**  
- What is Excel used for in business, analytics, and data engineering?  
- What is a **workbook**?  
  - How many worksheets can a workbook contain?  
  - What are the advantages of keeping multiple sheets in one workbook?  
- What is a **worksheet**?  
  - How is a worksheet structured (rows, columns, grid)?  
  - What is the maximum number of rows and columns in modern Excel?  
- What is a **cell**?  
  - What types of data can a cell store?  
  - What is a cell address?  
  - What is the difference between cell content and cell display?  
- What is a **range**?  
  - How do you select contiguous vs non-contiguous ranges?  
  - How do you name a range?  
- What is the **Ribbon**?  
  - What are the main Ribbon tabs (Home, Insert, Page Layout, Formulas, Data, Review, View)?  
  - What commands are commonly used in each tab?  
- What is the **Formula Bar**?  
  - How does it differ from the cell display?  
- What is the **Status Bar**?  
  - What information does it show (sum, average, count)?  
- What are **workbook views** (Normal, Page Layout, Page Break Preview)?  
- What are the most important **keyboard shortcuts** for navigation?  
- What is the difference between **Save** and **Save As**?  
- What is the difference between **Excel file formats** (.xlsx, .xls, .csv)?  
- Why is workbook structure important for data analysis?

### **Hands-On Practice (2 hours)**  
- Create a workbook with 3 worksheets: 
- Rename worksheets meaningfully  - “Employees”, “Sales”, “Products”.  
- Practice selecting ranges using mouse + keyboard.  
- Practice navigating using shortcuts (Ctrl + Arrow, Ctrl + Home, Ctrl + End).  
- Enter sample data into cells and observe formula bar behavior.  
- Use Status Bar to check quick calculations.  
- Save workbook in .xlsx and .csv formats.

### **Reflection (1 hour)**  
- Can you explain workbook vs worksheet vs cell vs range?  
- Can you navigate a large sheet without using the mouse?
