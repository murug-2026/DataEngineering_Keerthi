Day 3 is where you start connecting the *building blocks of databases* with how data is stored and represented.  
Here’s the **right set of questions** you should aim to answer 

---

## 📊 **Day 3 Learning Questions**

### **1. Rows & Records**
- What is a **row** in a database table?  
- Why is a row also called a **record**?  
- What does a record represent in real life (e.g., one student, one transaction)?  
- How do rows differ from columns in terms of meaning?  
- Can two rows be identical? What happens if they are?

---

### **2. Columns & Fields**
- What is a **column** in a database table?  
- Why is a column also called a **field**?  
- What does a field represent in real life (e.g., student name, transaction amount)?  
- How do columns define the **structure** of a table?  
- What is the difference between a **field name** and a **field value**?

---

### **3. Data Types**
- What are **data types** in databases?  
- Why do we need data types instead of storing everything as text?  
- What are the most common data types?
  - Integer  
  - Float/Decimal  
  - Text/String  
  - Date/Time  
  - Boolean (True/False)  
- What happens if you store wrong data in a column (e.g., text in a numeric field)?  
- How do data types help in **validation** and **efficient storage**?

---

### **4. Data Formats**
- What is the difference between **data type** and **data format**?  
- What are examples of formats for:
  - Date (DD-MM-YYYY, MM/DD/YYYY, ISO 8601)  
  - Time (24-hour vs 12-hour)  
  - Currency (₹, $, €)  
  - Phone numbers (+91-9876543210 vs 09876543210)  
- Why do formats matter in **data consistency**?  
- What problems occur if formats are inconsistent across systems?  
- How do you convert data from one format to another?

---

### **5. Practical Thinking Questions**
- If you design a student table, what rows and columns will you include?  
- How do you decide which data type to assign to each column?  
- What happens if you store dates as text instead of proper date type?  
- Why is it important to enforce consistent formats in a database?  
- How do rows, columns, records, fields, data types, and formats all connect together?

---

### **6. Hands-On Practice Questions**
- Create a table of employees with columns:
  - id (integer), name (text), age (integer), joining_date (date), is_active (boolean).  
- Insert 3 sample rows (records).  
- Identify:
  - Which are rows?  
  - Which are columns?  
  - Which are fields?  
- Try storing a wrong value (e.g., “abc” in age). What happens?  
- Format a date in different styles (DD-MM-YYYY vs YYYY-MM-DD).  

---

### **7. Reflection Questions (End of Day)**
- Can you clearly explain the difference between row and column?  
- Can you give real-world examples of records and fields?  
- Can you list 5 common data types and their uses?  
- Can you explain why formats matter in data science?  
- Can you design a small table with correct data types and formats?
