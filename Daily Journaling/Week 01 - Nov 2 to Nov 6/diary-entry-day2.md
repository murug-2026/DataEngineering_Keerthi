# DATA FUNDAMENTALS

## 1. What Is Data in Its Simplest Sense?

1. Data refers to raw facts, figures, observations or details collected from different sources.
2. It can include numbers, text, images, videos, audio and measurements.
3. Data by itself may not have a clear meaning without context.
4. It is the basic input used for information, analysis and decision-making.
5. Examples include names, ages, marks, temperatures and sales figures.

## 2. What Is the Difference Between Data and Information?

1. Data consists of raw facts and figures without interpretation.
2. Information is processed and organised data that provides meaning.
3. Data is the input, whereas information is the meaningful output.
4. Data may not directly support decisions, but information helps decision-making.
5. Example: Individual marks are data; the class average is information.

## 3. What Are the Different Types of Data?

1. Numerical Data represents quantities and measurements.
2. Categorical Data represents groups, labels and classifications.
3. Text Data contains written words and sentences.
4. Time-Series and Spatial Data represent information over time and geographical locations.
5. Data can also be classified as structured, semi-structured and unstructured.

## 4. What Is Qualitative Data vs Quantitative Data?

1. Qualitative data describes characteristics, qualities and categories.
2. Quantitative data represents measurable numerical values.
3. Qualitative data includes nominal and ordinal categories.
4. Quantitative data includes discrete and continuous values.
5. Examples: Eye colour is qualitative; age and salary are quantitative.

## 5. What Is Raw Data vs Processed Data?

1. Raw data is original information collected directly from different sources.
2. It may contain errors, duplicates, missing values and inconsistencies.
3. Processed data is cleaned, organised and transformed raw data.
4. Processing makes data easier to understand, analyse and interpret.
5. Example: Individual sales transactions are raw data; monthly sales reports are processed data.

## 6. Why Is Data the Foundation of Data Science?

1. Data provides the essential input required for Data Science.
2. Data scientists use it to identify patterns, trends and relationships.
3. It helps build statistical and Machine Learning models.
4. Historical data can be used to make predictions and forecasts.
5. Without relevant and reliable data, meaningful analysis and predictions are difficult.

## 7. What Makes Data Good or Bad?

1. Good data is accurate, complete, consistent, relevant and up to date.
2. Bad data contains errors, missing values, duplicates and inconsistencies.
3. Reliable data improves analysis and decision-making.
4. Poor-quality data can produce misleading results and incorrect predictions.
5. Data cleaning helps improve data quality and reliability.

## 8. What Is Information?

1. Information is data that has been processed, organised and interpreted.
2. It provides meaning and context to raw facts and figures.
3. Information helps people understand situations and identify patterns.
4. It supports planning, problem-solving and business decisions.
5. Example: Daily sales figures become information when summarised into a sales report.

## 9. How Does Data Become Information?

1. Data is first collected from different sources.
2. It is cleaned to remove errors, duplicates and inconsistencies.
3. The cleaned data is organised into a meaningful format.
4. It is processed and analysed to identify patterns and results.
5. The final output becomes meaningful information for decision-making.

## 10. What Is Context and Why Is It Important?

1. Context refers to the background or circumstances surrounding a piece of data.
2. It explains what the data represents and why it matters.
3. Context helps interpret data correctly.
4. The same numerical value can have different meanings in different situations.
5. It prevents misunderstandings and supports accurate decision-making.

## 11. Can the Same Data Give Different Information Depending on Context?

1. Yes, the same data can represent different information depending on its context.
2. A temperature of 38°C may indicate hot weather or a human fever.
3. ₹10 lakh in sales may be high for a small business but low for a large company.
4. An 80% examination score may be good or poor depending on the grading standard.
5. Context determines how data should be interpreted and understood.

## 12. Why Do Businesses Rely on Information Rather Than Raw Data?

1. Information provides meaningful insights instead of disconnected facts.
2. It helps businesses understand performance and customer behaviour.
3. It identifies trends, opportunities and potential problems.
4. It supports planning, forecasting and strategic decisions.
5. Information helps businesses make faster and more informed decisions.

## 13. What Is a Database and Why Is It Needed?

1. A database is an organised collection of related data stored electronically.
2. It allows users to store, retrieve, update and manage information.
3. Databases help organise large amounts of information efficiently.
4. They support data security, consistency and controlled access.
5. Examples include customer databases, banking databases and hospital databases.

## 14. What Is the Difference Between a Database and a DBMS?

1. A database is an organised collection of stored data.
2. DBMS stands for Database Management System.
3. A DBMS is software used to create, manage and control databases.
4. It allows users to insert, retrieve, update and delete records.
5. Examples of DBMS software include MySQL, PostgreSQL and Oracle Database.

## 15. What Are the Main Types of Databases?

1. Relational databases store information in tables containing rows and columns.
2. NoSQL databases support flexible non-relational data models.
3. Hierarchical databases organise data in a tree-like structure.
4. Network databases represent data using interconnected records.
5. Other types include object-oriented, distributed, cloud and graph databases.

## 16. What Are Tables, Rows, Columns, Primary Keys and Foreign Keys?

1. A table stores related information in rows and columns.
2. A row represents an individual record in a table.
3. A column represents a specific attribute or field.
4. A primary key uniquely identifies each record in a table.
5. A foreign key connects tables by referencing a key in another table.

## 17. What Is a Database Schema?

1. A database schema is the logical structure or blueprint of a database.
2. It defines tables, columns, data types and relationships.
3. It specifies primary keys, foreign keys and constraints.
4. It determines how information is organised and stored.
5. A schema describes the database structure rather than the actual stored records.

## 18. Why Do Relational Databases Enforce Structure?

1. Relational databases organise data into predefined tables, rows and columns.
2. They enforce data types, primary keys, foreign keys and constraints.
3. Structure helps maintain data accuracy and consistency.
4. It prevents invalid entries, duplication and incorrect relationships.
5. This makes data reliable, searchable and easier to analyse.

## 19. Why Do NoSQL Databases Allow Flexibility?

1. NoSQL databases do not always require a fixed predefined schema.
2. Different records can contain different fields and attributes.
3. They can handle diverse data formats and changing requirements.
4. This makes application development and data storage more adaptable.
5. Examples include MongoDB, Cassandra and Redis.

## 20. What Is Structured Data?

1. Structured data is information organised in a predefined format.
2. It is generally stored in tables containing rows and columns.
3. Each column represents a specific attribute or field.
4. It is easy to search, retrieve, process and analyse.
5. Examples include customer records, employee details and sales transactions.

## 21. What Is Unstructured Data?

1. Unstructured data is information that does not follow a fixed tabular format.
2. It does not have a predefined arrangement of rows and columns.
3. It includes images, videos, audio recordings, emails and documents.
4. It often requires specialised tools such as AI and Machine Learning for analysis.
5. Examples include CCTV footage, photographs and social media posts.

## 22. What Is Semi-Structured Data (JSON, XML)?

1. Semi-structured data does not follow a rigid relational table structure.
2. It contains organisational elements such as keys, values and tags.
3. JSON (JavaScript Object Notation) organises information using key-value pairs.
4. XML (Extensible Markup Language) organises information using custom tags.
5. Examples include API responses, configuration files and application data.

## 23. Why Do Companies Generate More Unstructured Data Today?

1. Increased smartphone usage generates photographs, videos and audio recordings.
2. Social media platforms generate posts, comments, messages and customer reviews.
3. E-commerce platforms collect product images, videos and customer feedback.
4. IoT devices and digital communication generate continuous streams of information.
5. AI and cloud technologies further increase digital content creation and storage.

## 24. What Tools Handle Structured Data Well (SQL Databases)?

1. SQL databases are designed to store and manage structured data in tables.
2. SQL (Structured Query Language) is used to retrieve and manipulate database information.
3. MySQL and PostgreSQL are popular open-source relational database systems.
4. Microsoft SQL Server and Oracle Database are widely used in businesses.
5. SQLite is a lightweight relational database commonly used in applications.

## 25. What Tools Handle Unstructured Data Well (NoSQL, Hadoop, Cloud Storage)?

1. NoSQL databases such as MongoDB store flexible, document-oriented data.
2. Hadoop supports distributed storage and processing of large datasets.
3. Cloud storage services such as Amazon S3 store images, videos and documents.

## 26. Why Is Unstructured Data Harder to Analyse?

1. Unstructured data does not follow a predefined format or fixed structure.
2. It contains different formats such as text, images, videos and audio.
3. Extracting meaningful information requires additional processing.
4. It often needs specialised technologies such as NLP, AI and Computer Vision.
5. Large volumes, inconsistent formats and poor data quality make analysis more complex.

## 27. How Does Structured Data Help in Machine Learning?

1. Structured data provides organised information for training Machine Learning algorithms.
2. Algorithms identify patterns and relationships between different variables.
3. Historical data helps models classify information and predict future outcomes.
4. Clean and consistent data can improve model performance and reliability.
5. Applications include fraud detection, sales forecasting and product recommendations.
