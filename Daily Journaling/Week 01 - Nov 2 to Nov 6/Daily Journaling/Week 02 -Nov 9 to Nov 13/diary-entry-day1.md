# Excel Fundamentals

### 1. Uses of Excel
Excel is used to store, organise, calculate, analyse, and visualise data. It supports business reporting, data analytics, and basic data engineering tasks.

### 2. Workbook
A workbook is an Excel file containing one or more worksheets. Its default file extension is `.xlsx`.

### 3. Worksheets in a Workbook
A workbook can contain as many worksheets as available system memory allows. There is no fixed maximum.

### 4. Advantages of Multiple Sheets
Multiple sheets help organise related data, compare information, link formulas, and simplify reporting within one file.

### 5. Worksheet
A worksheet is an individual spreadsheet inside a workbook, consisting of rows, columns, and cells.

### 6. Worksheet Structure
A worksheet is a grid of horizontal rows and vertical columns. Their intersection forms cells.

### 7. Maximum Rows and Columns
Modern Excel supports **1,048,576 rows** and **16,384 columns (A to XFD)** per worksheet.

### 8. Cell
A cell is the intersection of a row and column where data is entered and stored.

### 9. Types of Cell Data
Cells can store text, numbers, dates, time, formulas, logical values (TRUE/FALSE), and error values.

### 10. Cell Address
A cell address identifies a cell using its column letter and row number. Example: A1, B2, C5.

### 11. Cell Content vs Cell Display
Cell content is the actual stored value, while cell display is how that value appears through formatting.

### 12. Range
A range is a group of selected cells. Example: `A1:A5` or `A1:C5`.

### 13. Contiguous vs Non-Contiguous Ranges
- **Contiguous:** Adjacent cells selected together using dragging or Shift.
- **Non-contiguous:** Separate cells selected using Ctrl on Windows.

### 14. Naming a Range
Select cells, enter a name in the Name Box, and press Enter. Example: `Sales_Data`.

### 15. Ribbon
The Ribbon is Excel's main toolbar, containing tabs and commands for different tasks.

### 16. Main Ribbon Tabs
- **Home:** Formatting and editing.
- **Insert:** Tables, charts, and pictures.
- **Page Layout:** Page setup and printing.
- **Formulas:** Functions and calculations.
- **Data:** Sorting, filtering, and cleaning.
- **Review:** Comments, spelling, and protection.
- **View:** Worksheet display and navigation.

### 17. Common Ribbon Commands
- **Home:** Copy, Paste, Font, Alignment.
- **Insert:** PivotTable, Charts, Tables.
- **Page Layout:** Margins, Orientation, Print Area.
- **Formulas:** SUM, IF, AVERAGE, Name Manager.
- **Data:** Sort, Filter, Remove Duplicates.
- **Review:** Spelling, Comments, Protect Sheet.
- **View:** Freeze Panes, Zoom, Gridlines.

### 18. Formula Bar
The Formula Bar displays and allows users to edit the content or formula of a selected cell.

### 19. Formula Bar vs Cell Display
The Formula Bar shows the actual formula or content, while the cell display shows its calculated or formatted result.

### 20. Status Bar
The Status Bar is located at the bottom of Excel and displays information about selected cells and worksheet views.

### 21. Status Bar Information
- **Sum:** Total of selected numbers.
- **Average:** Average of selected numbers.
- **Count:** Number of non-empty selected cells.
- **Min/Max:** Smallest and largest numerical values.

### 22. Workbook Views
- **Normal:** Everyday data entry and editing.
- **Page Layout:** Preview printed appearance.
- **Page Break Preview:** Manage printed page divisions.

### 23. Important Navigation Shortcuts

| Shortcut | Function |
|---|---|
| Ctrl + Home | Go to A1 |
| Ctrl + End | Go to last used cell |
| Ctrl + Arrow | Jump across data |
| Ctrl + Page Up | Previous sheet |
| Ctrl + Page Down | Next sheet |
| Ctrl + F | Find data |
| Ctrl + S | Save workbook |
| F5 | Go To |

### 24. Save vs Save As
- **Save (Ctrl + S):** Updates the existing workbook.
- **Save As (F12):** Creates a new file with a different name, location, or format.

### 25. Importance of Workbook Structure
A well-organised workbook improves data accuracy, accessibility, comparison, and reporting. It makes data analysis and business decision-making easier.
