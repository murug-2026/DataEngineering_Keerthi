# MONTH 5: Power BI and Data Visualization

This should be one of the most intensive phases because Power BI skills provide a practical route into entry-level IT positions.

**Objective:** Build professional dashboards and understand the complete BI development process.

### Week 17: Power BI Fundamentals

| Day   | 3 Hours: Concepts + Documentation                     | 2 Hours: Hands-on Activity           |
| ----- | ----------------------------------------------------- | ------------------------------------ |
| Day 1 | Introduction to BI and Power BI architecture          | Install and explore Power BI Desktop |
| Day 2 | Power BI data sources and connectivity                | Import Excel and CSV                 |
| Day 3 | Power Query within Power BI                           | Clean and transform data             |
| Day 4 | Loading data and managing queries                     | Create a multi-table data model      |
| Day 5 | Power BI report canvas and visualisation fundamentals | Create an initial report             |

Deliverables:

* Power BI fundamentals document.
* Initial business report.

### Week 18: Data Modelling in Power BI

| Day   | 3 Hours: Concepts + Documentation                      | 2 Hours: Hands-on Activity         |
| ----- | ------------------------------------------------------ | ---------------------------------- |
| Day 1 | Data modelling fundamentals                            | Identify fact and dimension tables |
| Day 2 | Star schema and snowflake schema                       | Design a star schema               |
| Day 3 | Relationships and cardinality                          | Create table relationships         |
| Day 4 | Active/inactive relationships and filter direction     | Configure model relationships      |
| Day 5 | Introduction to DAX and calculated columns vs measures | Create basic measures              |

Deliverables:

* Power BI data model.
* Star schema diagram.
* DAX reference document.

### Week 19: DAX and Business Calculations

| Day   | 3 Hours: Concepts + Documentation               | 2 Hours: Hands-on Activity  |
| ----- | ----------------------------------------------- | --------------------------- |
| Day 1 | DAX fundamentals and syntax                     | Create calculated measures  |
| Day 2 | SUM, COUNT, DISTINCTCOUNT, DIVIDE               | Calculate KPIs              |
| Day 3 | CALCULATE, FILTER and context concepts          | Build business calculations |
| Day 4 | Time intelligence: YTD, MTD and previous period | Create time-based measures  |
| Day 5 | DAX troubleshooting and validation              | Validate KPI calculations   |

Deliverables:

* DAX measure library.
* Business KPI report.

### Week 20: Advanced Visualization and Dashboard Design

| Day   | 3 Hours: Concepts + Documentation                             | 2 Hours: Hands-on Activity   |
| ----- | ------------------------------------------------------------- | ---------------------------- |
| Day 1 | Data visualization principles and choosing appropriate charts | Build visual comparisons     |
| Day 2 | KPI cards, bar charts, line charts, maps and tables           | Create dashboard components  |
| Day 3 | Drill-through, tooltips, slicers and bookmarks                | Build interactive dashboards |
| Day 4 | Dashboard layout, colour theory and visual hierarchy          | Improve dashboard design     |
| Day 5 | Business storytelling and executive reporting                 | Build an executive dashboard |

Deliverables:

* Interactive Power BI dashboard.
* Dashboard design standards document.
